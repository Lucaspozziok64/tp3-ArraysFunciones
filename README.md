🚀 Tp3-Arrays y Funciones
==============================
Repositorio con ejercicios prácticos sobre arrays y funciones en javascrip, cada uno con su HTML y estilos CSS .
###

📂 Estructura del proyecto
````
.
├── /js/
│   ├── ejercicios/       # 7 archivos .js con soluciones
│   │   ├── ejercicio-1.js
│   │   ├── ejercicio-2.js
│   │   ├── ejercicio-3.js
│   │   ├── ejercicio-4.js
│   │   ├── ejercicio-5.js
│   │   ├── ejercicio-6.js
│   │   └── ejercicio-7.js
│   │ 
│   │
│   └── main.js           # Script principal
│
├── /css/
│   └── styles.css        # Estilos generales
│
└── /html/
    ├── index.html        # Página principal
    └── ejercicios/       # HTML individual para cada ejercicio
````
🛠️ Tecnologías utilizadas
- 
- HTML
- CSS
- Javascript
